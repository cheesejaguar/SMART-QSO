# On-Board Computer (OBC) Design Document (superseded)

This file is superseded and is kept only so that existing references still resolve.

On 2026-10-16 it was merged into [hardware/obc/OBC_DESIGN.md](../../hardware/obc/OBC_DESIGN.md) (SQSO-CDH-OBC-001
Version 1.1) as Appendix A. Appendix A.1 there lists where the two documents disagree; the GPIO table with the
2026-10-15 telecommand and deployment lines (finding SW-10) is Appendix A.5.4. The baseline OBC is the STM32L4R5ZI
([BASELINE_PARAMETERS.md](../BASELINE_PARAMETERS.md) §6). The previous text is in the Git history of this file.

The controlled list of documents is [DOCUMENT_REGISTER.md](../DOCUMENT_REGISTER.md).
