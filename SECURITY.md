# Security Policy

- **Scope:** Software and documentation only (no export‑controlled content).
- **Report vulnerabilities:** no private reporting address has been set up yet. Until one is, open a GitHub issue that asks the maintainer for a private channel, without exploit details. Telecommand keys are never in the repository (`docs/BASELINE_PARAMETERS.md` §7).
- **Coordinated disclosure:** We target 90 days to patch and disclose.
