A packet station is enough to start.

The first service targets ordinary licensed amateur operators and educational clubs. The satellite is not in orbit. You can run a local ground demonstration now, contribute engineering work, or help establish a sponsoring institution.

Try the ground demonstration

Download the complete development source and verification package, extract it, and run these commands from its root. It includes source for the current demonstration, reference firmware and actual test reports. The firmware is unprovisioned and has not been executed on hardware.

Development source and evidence · ZIP · Manifest · SHA-256 checksums · Dependency inventory

uv sync --extra dev
cmake -S software/flight -B build
cmake --build build
npm --prefix software/web ci
npm --prefix software/web run build
uv run python -m software.ground.service.app

Open the local mission console. All data is labeled simulation. Core service remains available without a language model, credentials or an RF device.

Use a KISS-compatible TNC

Create a packet without sending it:

uv run python -m software.ground.client.packet --from W6ABC --to K6XYZ --text "Hello from our club"

On-air use requires your licensed station, the appropriate coordinated operating frequencies and an explicit --send --port invocation. The client does not silently transmit.

During a contact, use --request to retrieve messages for your station. After receiving a message, use --ack ID to record its receipt. These commands are also dry-run unless --send is explicit. Replace the development satellite address with the coordinated callsign before on-air operation.

Contribute evidence

Priority work includes measured full-cycle language-payload energy, reference radio interoperability, subsystem hardware selection, conductive vacuum cooling, battery and inhibit tests, and independent requirements review.

Institutional participation

We need named accountable engineers, a sponsoring educational or nonprofit organization, facilities and supplier quotations. Funding and launch support are not secured. The proposal describes staged, reviewable milestones.
